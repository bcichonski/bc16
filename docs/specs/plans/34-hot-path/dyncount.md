## 1. Instructions per call

Executed instructions from the `cal` at the use site up to and including the return to the caller (inline: from the first body instruction to the one after the body). Today's option is marked with `*`.

- **1 ROM call**: runtime stub `mov a,<idx>; psh a; pop f; cal :os_metacall; ret` -> `os_metacall` (0x0008) -> `os_call` (saves 5 regs, looks up `os_metatab`, ROM `cal :poke16` into `var_oscalladdr`, restores) -> `cal :var_oscall` -> ROM body -> returns. Index poke16 0x09, peek16 0x0a, gt16 0x21, gteq16 0x22, eq16 0x23.
- **2 private copy**: the ROM body copied into the program (comparisons: its own `*_false` label for eq16), `cal :routine` at the use site.
- **3 inline**: the body without `cal`/`ret`. A non-final exit becomes an unconditional jump to the end, written as the flag-setting result load followed by `jmr z`/`jmr nz` (`mov`/`xor` set the flags), so it costs the same instruction the `ret` did; the last exit falls through.

## 2. Dynamic call counts

Method: the emulator loop is hooked in-process and counts every instruction fetch whose PC is the address of a routine, using the symbol addresses the assembler reports for each program image (bdos at 0x0f00; the user program loaded at 0x6000 is identified by comparing the memory image with each built program when execution enters 0x6000) and for the ROM. A *program call* is an entry to the routine label inside a loaded program: for peek16/poke16 that is the private copy, for gt16/gteq16/eq16 it is the ROM-call stub. ROM bodies entered through `var_oscall` (ROM-call dispatch) are counted separately and equal the stub entries (asserted by the script); ROM bodies entered by a direct `cal` inside the ROM (including `os_call`'s own `cal :poke16`) are not affected by the options and are listed as information.

Sessions (keys typed in a scripted run on temp copies of `os.bdd`/`utils.bdd`):

- `boot`: boot bdos only (type `exit`) (`exit\n`) - 68,263 instructions executed
- `ls`: boot bdos, `ls`, `exit` (`ls\nexit\n`) - 444,454 instructions executed
- `texted`: boot bdos, texted on B: insert 3 lines, save, load, print, quit (from test_e2e_texted) (`b:\ntexted\ni 10 10\nfirst line\nsecond line\nthird line\n\ns note.txt\nl note.txt\np 0 65535\nq\nexit\n`) - 979,048 instructions executed
